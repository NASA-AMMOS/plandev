SeqDev is a software application for creating, authoring, and validating the contents of sequences and providing ground system integration capabilities. Sequences, also known as command lists, are authored in a collaborative workspaces where users can prepare files to be sent to a spacecraft or testbed. SeqDev provides IDE inspired capabilities including validation of commands against the active command dictionary allowing for a faster feedback and authoring valid sequences the first time. Additionally the actions feature provides adaptation specific configuration managed interactions with supplementary external capabilities like flight rule checkers or compilation tool chains. This ensures that spacecraft operations teams are using the mission validated workflow to check and deliver uplink products.

## SeqDev & PlanDev Naming

As new mission communities have joined SeqDev, we've evolved our product focus and naming. What you need to know:

* The sequencing tool is now named SeqDev and the planning tool is now named PlanDev 
* Most repositories have been renamed, and the rest will be renamed soon. The repository code structure has not changed
* Published code packages (NPM, Java, and Docker images) still retain their **old** names but will be renamed in a future version
* Changes affecting your code will be announced in advance with upgrade guidance

For the latest documentation, visit: [SeqDev Documentation](https://nasa-ammos.github.io/plandev-docs/sequencing/introduction/)
